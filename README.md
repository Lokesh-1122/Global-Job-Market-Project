# 🌍 Global AI Job Market & Salary Analysis Dashboard

An interactive data visualization project that analyzes global AI job market trends using real-world job posting data. This project explores salary distributions, experience levels, skill demand, company characteristics, and geographic hiring trends through insightful visualizations and an interactive Streamlit dashboard.



## 📖 Project Overview

The rapid growth of Artificial Intelligence has significantly transformed the global job market. This project aims to analyze AI job postings to understand hiring trends, salary patterns, and the most in-demand skills across different industries and countries.

The analysis is performed using Python for data processing and visualization, while Streamlit is used to build an interactive dashboard that allows users to explore the data dynamically.


## 🎯 Project Objectives

- Analyze global AI job market trends.
- Identify the most in-demand AI skills.
- Compare salaries across experience levels.
- Explore salary variations by company size and location.
- Examine industry-wise hiring patterns.
- Build an interactive dashboard for data exploration.



## 📂 Dataset

The project uses two real-world datasets:

- **ai_job_dataset.csv**
- **ai_job_dataset1.csv**

The datasets contain information such as:

- Job ID
- Job Title
- Experience Level
- Required Skills
- Company Name
- Company Location
- Company Size
- Industry
- Employment Type
- Salary (USD)
- Remote Work Ratio
- Posting Date
- Years of Experience
- Education Requirement

## 📈 Key Insights

- Python, SQL, and Machine Learning are among the most frequently requested AI skills.
- Senior and Executive positions receive the highest average salaries.
- AI job opportunities are concentrated in leading technology markets.
- Company size influences salary levels.
- Remote work has become a significant hiring trend in the AI industry.
- Mid-level and Senior positions account for a large share of AI job postings.
